# Sinhala Font Converter Web

A utility to convert Sinhala text between Unicode and legacy font encodings (such as FM Abhaya and Isiwara) in real time. Built this for my personal use as a Graphic Designer but this tool is completely free for anyone to use.

## Features

- **Real-Time Conversion:** Instant text mapping as you type or paste.
- **Legacy Font Support:** Accurate conversion between Sinhala Unicode, FM Abhaya and Isi fonts.
- **One-Click Copy & Clear:** Quickly copy converted text for use in Adobe Photoshop, Illustrator, or desktop publishing tools.
- **Responsive UI:** Clean, distraction-free interface that works on desktop and mobile.

## Tech Stack

- **Frontend:** React, Tailwind CSS
